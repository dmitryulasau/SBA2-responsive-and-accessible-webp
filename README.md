# Accessible Design Co. Website Plan

### Sections

## `HEADER`

- Added a placeholder image for the company logo.
- Created a responsive navigation bar using Flexbox, with links to different sections.

## `HERO`

- Added a background image.
- Added a welcome heading.
- Added a call to action (CTA) button.

## `ABOUT US`

- Added a short company description using semantic HTML.

## `SERVICES`

- Each service includes an icon and description.
- CSS Grid layout.

## `CONTACT`

- Contact information with phone, email, and location icons.
- Contact form with Name, Email, Subject, and Message fields.
- Required fields are marked with red asterisks.
- A "Send Message" button.

## `FOOTER`

- Copyright information.
- LinkedIn link with icon.

### Requirements

- Semantic HTML.
- Responsive design.
- Flexbox for navigation.
- CSS Grid for service cards.
- Accessible labels, ARIA attributes, and image alt text.
- Visible keyboard focus states.
- Good color contrast.
- Responsive media queries.
