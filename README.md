# Accessible Design Co. Website Plan

### Sections

## `HEADER`
- Added a placeholder image for the company logo.
- Created a responsive navigation bar using Flexbox, with links to different sections.

## `HERO`
- Added a background image.
- Added a welcome heading.
- Added a call to action (CTA) button.

## `ABOUT US`
- Added a short company description using semantic HTML elements.

## `SERVICES` - A grid-based layout that showcases different services the company offers, with icons or images and short descriptions.
## `CONTACT` - A form for users to get in touch, including fields for “Name,” “Email,” “Subject,” and “Message,” with accessible labels and ARIA attributes.
## `FOOTER` - A footer with copyright information, social media links, and contact details.


### Requirements
- Semantic HTML.
- Responsive design.
- Flexbox for navigation.
- CSS Grid for service cards.
- Accessible labels, ARIA attributes, and image alt text.
- Visible keyboard focus states.
- Good color contrast.
- Media queries at 600px and 1024px.
