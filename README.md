# Accessible Design Co. Website Plan

### Sections

- `HEADER` -Logo and responsive navigation (Flexbox).
- `HERO` - Background image, welcome heading, and CTA button.
- `ABOUT US` - Company description and image.
- `SERVICES` - Three service cards using CSS Grid.
- `CONTACT` - Contact information and accessible form.
- `FOOTER` - Copyright and social media links.

### Requirements
- Semantic HTML.
- Responsive design.
- Flexbox for navigation.
- CSS Grid for service cards.
- Accessible labels, ARIA attributes, and image alt text.
- Visible keyboard focus states.
- Good color contrast.
- Media queries at 600px and 1024px.
